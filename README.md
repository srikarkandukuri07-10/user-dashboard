# User Dashboard & Booking System

This repository contains both components of the booking and order dashboard system.

## Project Structure

1. **[booking](./booking/)**: The client-side customer application where users can view the menu, select a table, place orders, and track order status in real-time.
2. **[booki-back](./booki-back/)**: The admin and kitchen dashboard backend application built with Next.js, WebSockets (Socket.IO), and Prisma/PostgreSQL database to manage orders, menus, and real-time updates.
